# MarkFlow：Markdown 内容排版工作台

MarkFlow 是一个面向内容创作者、技术写作者和自媒体运营者的 Markdown 内容排版工作台。

你可以在这里完成从 Markdown 写作、实时预览、样式调整到多格式导出的完整流程。它适合用来整理公众号文章、技术博客、教程、项目说明、版本说明和产品介绍。

## MarkFlow 能做什么

- 新增或导入 Markdown 内容，快速进入编辑状态
- 实时预览排版效果
- 调整主题、字号、颜色和代码块样式
- 插入图片、公式和表格
- 导出 Markdown、HTML、无样式 HTML、PDF 和 PNG
- 将排版后的 HTML 内容复制到公众号或其他内容平台
- 管理本地内容、模板和项目配置

## 适合谁使用

- 需要高效排版公众号文章的内容创作者
- 经常写技术文章、教程和项目说明的开发者
- 想把 Markdown 转成 HTML、PDF 或图片的写作者
- 需要统一整理长文内容并发布到不同平台的运营者

## 为什么做 MarkFlow

Markdown 很适合写作，但最终发布到不同平台时，常常还需要处理样式、格式和导出问题。MarkFlow 希望把这些流程放到一个清晰的桌面工作台里，让内容从草稿到发布更顺。
